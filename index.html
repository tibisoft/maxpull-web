How it works

One question decides tomorrow's plan.

Every session ends with Easy, Normal, or Hard. That single answer is the entire algorithm — no manuals, no macros to log.

EASY
Working max climbsNail the set and next time's target moves up.
NORMAL
Climbs every other timeTwo solid Normals in a row nudge the max up; one alone just holds the line.
HARD, TWICE
It backs offStruggle two sessions running and the plan eases up.
Every 18 days, an AMRAP retest checks your plan against reality — so the number driving your training never drifts too far from the truth.

Built for the bar

Made for mid-set, not the menu.

  • Log each set right off the barReps are logged after the set, not tapped in live — on the bar, both hands are busy. Drop off, tap in the number, move on.
  • Undo the last setLogged the wrong number? One tap fixes it, no restarting the workout.
  • No forced stopThe target's a floor, not a ceiling. Log more if you've got it in the tank.
  • Rest with a chimeA 75-second countdown between sets. Ready early? Skip it.
